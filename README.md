# make-the-ai-judge-feel-held

A tiny program that writes one short text to `/output/entry.txt` for the [make.fun](https://make.fun) competition "Make the AI judge feel held".

The text is written to slow a reader down: concrete images, a steady rhythm, and a closing line that keeps working after it is read.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (204 Unicode code points, UTF-8).
